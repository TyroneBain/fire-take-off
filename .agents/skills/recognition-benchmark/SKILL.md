# Independent recognition benchmark

## When to use
Use when assigned a bounded task in this specialty. The lead remains responsible for integration and file ownership.

## Procedure
Obtain licensed fixture and independently labeled ground truth before running the matcher. Capture symbol type, page, expected locations and ambiguity policy. Record TP/FP/FN, precision, recall, false positives per page, correction actions, task duration and memory. Reopen saved work, test zones, reconcile Excel. Compare competitor workflows only through permitted use. Record failures in a reproducible register; do not claim parity from synthetic tests.

## Deliverable
Provide: scope, evidence and source versions, changes or proposed changes, reproducible verification, measured outcomes, failures/unknowns, and next executable action. Do not silently modify unrelated production files.
