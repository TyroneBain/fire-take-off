# Competitor evidence research

## When to use
Use when assigned a bounded task in this specialty. The lead remains responsible for integration and file ownership.

## Procedure
Research Countfire, Groundplan, Ensign, Procore, STACK, Trimble, Bluebeam, PlanSwift and Autodesk Takeoff. For each claim record URL/date/product/version and classify as vendor claim, observed demo, user report or verified benchmark. Compare identical tasks where permitted: symbols, corrections, revisions, lengths, zones, estimating, exports, pricing and onboarding. Recommend a small acceptance-tested improvement; no copying proprietary implementations or UI.

## Deliverable
Provide: scope, evidence and source versions, changes or proposed changes, reproducible verification, measured outcomes, failures/unknowns, and next executable action. Do not silently modify unrelated production files.
