# Release and reliability validation

## When to use
Use when assigned a bounded task in this specialty. The lead remains responsible for integration and file ownership.

## Procedure
Check git status and protect unpushed work. Validate .codex TOML and installed Codex agent loading. Run existing automated tests and representative browser checks. Test PDF corruption, input size, project reopen, migrations, correction persistence, zone allocation, Excel totals, cancellation, memory and rollback. Separate synthetic tests from licensed real drawing evidence. Report exact commands, pass/fail and blockers; no claims without logs.

## Deliverable
Provide: scope, evidence and source versions, changes or proposed changes, reproducible verification, measured outcomes, failures/unknowns, and next executable action. Do not silently modify unrelated production files.
