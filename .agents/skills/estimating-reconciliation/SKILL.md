# Estimating reconciliation and simPRO research

## When to use
Use when assigned a bounded task in this specialty. The lead remains responsible for integration and file ownership.

## Procedure
Read docs/SIMPRO_ESTIMATING_INTEGRATION_RESEARCH.md. Model page/zone/floor/system/custom package allocation with unallocated bucket, non-overlap or explicit allocation precedence. Check per-item quantity rollups, labour/material rates, taxes, rounding, revision diffs, and workbook reopen. Investigate official simPRO APIs and import support, credentials/permissions and idempotent mapping; distinguish verified from hypothetical. Produce a reviewed dry-run export first; never push live quotes without approval.

## Deliverable
Provide: scope, evidence and source versions, changes or proposed changes, reproducible verification, measured outcomes, failures/unknowns, and next executable action. Do not silently modify unrelated production files.
