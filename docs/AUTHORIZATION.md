# Current product authorisation and IP boundaries

## Active direction — 2026-10-30
The owner wants Fire Take Off to perform automatic symbol takeoff as well as possible and as close to Countfire's practical counting experience as independently achievable. Prioritise: selecting symbol examples, automatically detecting matching symbols, applying consistent colour-coded marks and quantities, reviewing false positives/misses, retaining corrections, and exporting reconciled totals.

Countfire is a functional benchmark, not a template to copy. Implement independently with original code, visual identity, text, icons and layout. Avoid deliberately duplicating its distinctive visual expression. Preserve the familiar, efficient counting workflow where functionally justified; do not invent an inferior or unrelated counting method simply to differentiate the product.

Research public documentation and use authorised access only in accordance with applicable terms. Do not copy competitor source code, assets or proprietary materials; do not bypass access controls. A user authorisation is not a licence from Countfire. Patent, contract, trademark and design risks require separate review before commercial release.

Routine development, testing, documentation and private repository delivery are authorised. Preserve existing functionality and user data, avoid unrelated changes, and keep the catalogue deferred. Do not publish the repository or include customer drawings or credentials.
